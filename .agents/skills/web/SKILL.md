Check the installed React version, router, rendering model, and browser support
before using framework-specific examples. Next.js advice applies to Next.js;
do not install canary React or migrate the app merely to enable an animation.
Use the existing browser test runner and observable readiness conditions rather
than assuming network idle in a streaming chat app.

For additional platform conventions, consult the preserved
[web platform reference](../../upstream/ehmo-platform-design-skills/web/SKILL.md)
as needed. Shared design and animation skills remain outside this group.
